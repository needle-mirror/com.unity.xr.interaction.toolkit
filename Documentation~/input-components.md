# Input components

Reference documentation describing the controls and properties for the input-related components.

| **Topic**             | **Description**         |
| :-------------------- | :----------------------- |
| [Input Action Manager](input-action-manager.md)           | A utility component that enables or disables a list of input Actions. |
| [Press Scroll Input](press-scroll-input.md)               | Scrolls a fixed distance once per input event, such as a button press or microgesture swipe. |
| [XR Input Modality Manager](xr-input-modality-manager.md) | Swaps between XR controllers and hands based on what the player is using. |
| [XR Transform Stabilizer](xr-transform-stabilizer.md)     | Stabilizes XR pose input. |
